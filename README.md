# Калькулятор податків ФОП 2026

Статичний сайт: скільки платить ФОП 1–3 групи (єдиний податок, військовий збір, ЄСВ), використання ліміту доходу і найближчі строки сплати.

## Структура

- `src/page.html` — сторінка (вміст і стилі)
- `public/engine.js` — розрахунки; значення року в `RULES`
- `build.sh` — збирає `public/index.html`, `robots.txt`, `sitemap.xml`
- `tests/` — `npm test`

## Деплой на Vercel

1. Import Project → цей репозиторій. Framework: **Other**. Решта налаштувань береться з `vercel.json`.
2. Після підключення свого домену додайте змінну середовища `SITE_URL=https://ваш-домен` і зробіть Redeploy — це оновить canonical і sitemap.
3. Додайте сайт у Google Search Console і надішліть `sitemap.xml`.

## Щороку

Оновіть `RULES` у `public/engine.js` (мінімальна зарплата, прожитковий мінімум, ліміти), запустіть `npm test`.

Розрахунок довідковий і не є податковою консультацією.
